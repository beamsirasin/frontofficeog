รีเซ็ตรหัสผ่าน:

ไม่สามารถดูรหัสผ่านปัจจุบันได้ — พิมพ์รหัสผ่านใหม่ให้พนักงานโดยตรง เมื่อบันทึกแล้ว session ที่ล็อกอินค้างอยู่ทั้งหมดของบัญชีนี้จะถูกเพิกถอน และต้องล็อกอินใหม่

ตั้งรหัสผ่านใหม่สำเร็จ — เพิกถอน session เดิมทั้งหมดแล้ว
